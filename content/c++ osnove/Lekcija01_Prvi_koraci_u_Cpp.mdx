## `cout` - ispis podataka na ekran

Naredba <code>cout</code> služi za ispis podataka na ekran. To je prvi alat kojim program komunicira s korisnikom. Može ispisivati tekst, brojeve i vrijednosti spremljene u varijablama.

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "Pozdrav iz C++ programa!" << endl;
    return 0;
}
```

U ovom primjeru program ispisuje jednu tekstualnu poruku. Tekst koji se ispisuje mora biti unutar navodnika, jer se time označava da se radi o tekstualnom nizu znakova.

<ConceptGrid>
  <ConceptCard title="`cout`">
    Označava standardni izlaz. U početnim programima to znači ispis u konzolni prozor.
  </ConceptCard>
  <ConceptCard title="Operator `<<`">
    Ovaj operator šalje podatak prema izlazu. Može se koristiti više puta u istoj naredbi.
  </ConceptCard>
  <ConceptCard title="`endl`">
    Prelazi u novi red i završava trenutni ispis. U jednostavnim primjerima čini ispis preglednijim.
  </ConceptCard>
</ConceptGrid>

<InfoBox type="info" title="Važna razlika">
Tekst se piše unutar navodnika, ali naziv varijable ne. Ako se napiše <code>cout &lt;&lt; "broj";</code>, ispisat će se riječ <code>broj</code>. Ako se napiše <code>cout &lt;&lt; broj;</code>, ispisat će se vrijednost koja je spremljena u varijabli <code>broj</code>.
</InfoBox>

## `cin` - unos podataka s tipkovnice

Naredba <code>cin</code> služi za unos podataka koje korisnik upisuje tijekom rada programa. Ti podaci ne mogu se spremiti bilo gdje, nego moraju imati unaprijed pripremljeno mjesto u memoriji. To mjesto zove se varijabla.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int godine;

    cout << "Unesi broj godina: ";
    cin >> godine;

    cout << "Upisana vrijednost je: " << godine << endl;
    return 0;
}
```

Ovdje program prvo priprema varijablu <code>godine</code>, zatim traži unos od korisnika, sprema upisani podatak i na kraju ga ponovno ispisuje.

## Što je varijabla

Varijabla je imenovano mjesto u memoriji u koje program sprema podatak. Taj podatak može se kasnije koristiti, promijeniti ili ispisati. Bez varijabli program ne bi mogao pamtiti što je korisnik unio niti bi mogao raditi s međurezultatima.

<ConceptGrid>
  <ConceptCard title="Naziv varijable">
    Svaka varijabla mora imati naziv. Taj naziv treba biti jasan i smislen, jer olakšava čitanje programa.
  </ConceptCard>
  <ConceptCard title="Tip varijable">
    Tip govori koju vrstu podatka varijabla može spremiti. To određuje kako će se podatak koristiti u programu.
  </ConceptCard>
  <ConceptCard title="Vrijednost varijable">
    To je konkretan podatak koji je trenutno spremljen u varijabli.
  </ConceptCard>
</ConceptGrid>

Primjer deklaracije i pridruživanja vrijednosti:

```cpp
int broj = 25;
double cijena = 19.99;
char slovo = 'A';
string ime = "Ante";
```

Ovdje se vidi da različite vrste podataka traže različite tipove. Broj <code>25</code> može biti spremljen kao cijeli broj, decimalni broj <code>19.99</code> kao <code>double</code>, jedno slovo kao <code>char</code>, a tekst kao <code>string</code>.

<InfoBox type="warning" title="Što ovdje početnici najčešće pogriješe?">
Početnici često pomiješaju tekst i znak. U C++-u se tekst piše unutar dvostrukih navodnika, a jedan znak unutar jednostrukih. Zato <code>"A"</code> i <code>'A'</code> nisu isto.
</InfoBox>

## Pridruživanje i promjena vrijednosti

Vrijednost varijable ne mora ostati ista od početka do kraja programa. Program tijekom izvođenja može promijeniti vrijednost i nastaviti rad s novim podatkom.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int broj = 10;
    cout << "Početna vrijednost: " << broj << endl;

    broj = 25;
    cout << "Nova vrijednost: " << broj << endl;

    return 0;
}
```

Ovdje varijabla <code>broj</code> najprije ima vrijednost <code>10</code>, a zatim joj se pridružuje nova vrijednost <code>25</code>. Program više ne pamti staru vrijednost kao aktivnu, nego dalje radi s novom.

## Zadaci koji će se raditi na satu

Ovo nisu domaći zadaci, nego zadaci kroz koje će se voditi objašnjenje gradiva. Redoslijed je namjerno postavljen od jednostavnijeg prema zahtjevnijem.

### Zadatak 1 - Osnovni ispis

Napisati program koji ispisuje ime, prezime i naziv škole, svako u novom redu.

### Zadatak 2 - Unos jednog broja

Napisati program koji od korisnika traži jedan cijeli broj i zatim ispisuje rečenicu: `Unio si broj: ...`

### Zadatak 3 - Unos dva broja

Napisati program koji unosi dva cijela broja i ispisuje oba broja u jednoj rečenici.

### Zadatak 4 - Unos imena i dobi

Napisati program koji od korisnika traži ime i broj godina te na kraju ispisuje oblikovanu rečenicu s tim podacima.

### Zadatak 5 - Promjena vrijednosti varijable

Napisati program koji postavlja početnu vrijednost jedne varijable, ispisuje je, zatim joj pridružuje novu vrijednost i ponovno je ispisuje.

### Zadatak 6 - Teži zadatak za kraj sata

Napisati program koji unosi ime proizvoda, količinu i cijenu jednog proizvoda te na kraju ispisuje urednu tekstualnu rečenicu u kojoj su prikazani svi uneseni podaci.

## Domaći rad za Moodle VPL

Domaći rad će se rješavati preko Moodle VPL sustava. To znači da zadaci moraju biti napisani uredno, bez suvišnih dijelova i tako da se mogu normalno pokrenuti i provjeriti u sustavu.

### Obavezni zadaci

1. Napisati program koji unosi ime i prezime te ih ispisuje u jednoj punoj rečenici.
2. Napisati program koji unosi jedan cijeli broj i jedan decimalni broj te ispisuje obje vrijednosti.
3. Napisati program koji unosi naziv predmeta i ocjenu te ispisuje urednu poruku s oba podatka.
4. Napisati program koji unosi ime proizvoda i njegovu cijenu te ispisuje rezultat u obliku kratkog opisa.
5. Napisati program koji deklarira varijablu, ispisuje njezinu početnu vrijednost, zatim joj pridružuje novu vrijednost i ponovno ispisuje rezultat.

### Dodatni teži zadaci

1. Napisati program koji unosi naziv tvrtke, broj zaposlenika i prosječnu plaću te sve podatke ispisuje u jednoj smislenoj rečenici.
2. Napisati program koji unosi ime učenika, razred, omiljeni predmet i prosjek ocjena te na kraju ispisuje cjelovit sažetak unesenih podataka.
3. Napisati program koji unosi naziv putovanja, broj dana, cijenu po danu i ime putnika te ispisuje tekstualni prikaz svih unesenih vrijednosti.

<InfoBox type="warning" title="Pravila za predaju u Moodle VPL sustavu">
Program mora biti potpun i pokretljiv. Nazivi varijabli trebaju biti razumljivi, ispis treba biti uredan, a kod napisan tako da se iz njega jasno vidi što program radi. Neuredan kod i slučajno pogađanje rješenja ovdje ne prolaze dovoljno dobro.
</InfoBox>
